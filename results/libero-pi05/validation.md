# 物理与渲染一致性验证

本记录使用 MuJoCo 2.3.7 与 MotrixSim 社区版 0.10.1。诊断按三个问题设计：相同状态和输入下的物理响应是否一致，固定状态下的两路 RGB 是否一致，冻结策略能否在各自闭环里完成任务。最后一个问题只使用正式评测计分。

## 无渲染物理对照

先在两端还原关节、浮动基座、夹爪、固定家具及 OSC 复位记忆，统一 20 Hz 控制和 2 ms 物理步长。隔离控制器时比较相同执行器指令的一步响应；隔离接触时还原双方同一物理步的姿态和速度，连续回放用于观察误差积累。全部改动由 MJCF 参数决定。正式配置保留原始灶面和其余碰撞形状、位置、过滤规则，以及 SDK 的默认求解器。

| 现象 | 对照与处理 | 核验结果 |
|---|---|---|
| 预热后末端偏移 | 还原 LIBERO 的 OSC 初始目标、缓存状态和零空间姿态 | 10 项 Spatial 的 450 个留出初态全部改善，末端位置偏差中位数从 5.718 mm 降至 0.0121 mm |
| 视觉几何被计入惯量 | 按编译器的 `inertiagrouprange` 和继承默认类计算质量 | 10 项 Spatial 均匹配原生质量；5 类浮动物体质量最大相对误差 4.17×10⁻⁸，惯量张量 4.40×10⁻⁷ |
| 相同力矩下的无接触速度偏差 | 从原模型导出主惯量系与等效箱体，在 MotrixSim 每个物理步按速度、空气密度、黏度和风施加介质力 | 50 个诊断样本的机械臂关节速度 RMS 差中位数 2.246×10⁻⁵ → 6.403×10⁻⁷ rad/s；跨十任务的 100 个留出样本为 1.782×10⁻⁵ → 3.807×10⁻⁷ rad/s，逐样本均改善 |
| 首次接触后物体持续高速自转 | SDK 导入忽略自由关节声明的阻尼。对无活动子关节的刚体，用其空间惯量计算单步隐式黏性阻尼的等效外力和力矩 | 无接触 6 g 箱体以 10 rad/s 起转，四组姿态与质心设置下，旧导入一步仍是 10。原生和修复后均约 3.718 rad/s，最大角速度分量差约 1.2×10⁻⁶ rad/s。此前 Long 首任务初态 02 在开爪预热即发散，加入阻尼后连续 3,750 步保持有限；四套件的 200 个初态通过 15 个开爪控制步 |
| 初始轻微穿透导致过强冲击 | 原版先按优先级与 `solmix` 混合 `solref/solimp`，再对正时间常数执行 `refsafe` 的两物理步下限。转换器为异质的可碰撞几何对写入混合后的参数，同质材质共用其有效参数 | 对四套件 40 项各抽初态 02、11、21、31、41，在原生编译器中核对转换前后全部 8,215 个接触点。几何对、数量、位置、深度、摩擦维数、有效参数与阈值一致；其中 Goal 初态第一步没有接触 |

下表先固定阻尼、介质力和几何，再比较修正接触材质混合前后与 MuJoCo 的一步速度差。统计单位为每个官方初态中的每个浮动物体；同一物体的三个速度分量先取欧氏范数，再求样本均值。Goal 在这些初态只能核验自由运动。

| 套件 | 物体状态数 | 线速度差均值（mm/s） | 角速度差均值（rad/s） |
|---|---:|---:|---:|
| Spatial | 250 | 11.06 → 5.52 | 0.227 → 0.152 |
| Object | 350 | 5,609.72 → 96.32 | 0.344 → 0.0062 |
| Goal | 200 | 0.00243 → 0.00243 | 0.00000323 → 0.00000323 |
| Long | 200 | 2,150.74 → 1.25 | 0.692 → 0.0510 |

最终材质与阻尼配置还对 2,000 个官方初态全部执行了 15 个无渲染控制步（每例 375 个物理步），逐控制步检查广义速度有限性，2,000/2,000 通过。

### 落盘与留出复测

早期的 39/100 使用末尾连续五个物理步的接触标志。实际有 89/100 抬起后碰到盘，50 例在末尾只间断报告接触，其余 11 例没有进入落盘阶段。那 50 例在最后 100 ms 均已脱手，盘坐标系内水平活动范围最大 0.501 mm，最大连续接触空档为 4 ms。原始数据支持接触抖动。另有初态在释放后被夹爪再次托住，必须结合夹爪接触与相对轨迹判断。将物理步长改为 1 ms 曾改善接触连续性，额外留出组的任务成功却由 35/50 降为 32/50；正式步长保留 2 ms。

十个 Spatial 任务各取五个编号 01、11、21、31、41 的初态。每例使用原始 MuJoCo 的固定动作，原窗口结束后加一秒开爪。首次碰盘要求此前抬高至少 3 cm；连续接触取末尾五步；任务成功只看原窗口。

| 配置 | 抬起后碰盘 | 末尾连续接触 | 原窗口任务成功 |
|---|---:|---:|---:|
| 原有 OSC 与质量惯量修复 | 44/50 | 16/50 | 31/50 |
| 加入介质力 | 47/50 | 18/50 | 29/50 |
| 再加入自由关节阻尼与同质短时间常数修正，混合材质仍走 SDK 默认 | 47/50 | 47/50 | 31/50 |
| 最终的阻尼与材质混合配置 | 47/50 | 45/50 | 34/50 |

另用十个任务的 02、12、22、32、42 号初态，在配置冻结后复跑 50 次。首次碰盘 47/50 → 47/50，连续接触 27/50 → 44/50，原窗口任务成功 35/50 → 28/50。两个留出组都改善了连续支撑，但原任务成功一组上升、一组下降。固定的原生动作对轨迹偏差敏感，无法由此推算闭环收益。

## 渲染及贴图

两端在同一官方状态与家具布局下冻结物理，分别捕获外部和腕部相机。先用带方向标记的 UV 色卡区分翻转、缩放与光照偏差，再用真实材质重复。下列误差均为 8 位 RGB 的平均绝对通道差；区域、任务和相机决定了每个值的适用范围。

| 问题 | 通用处理 | 同状态核验 |
|---|---|---|
| 二进制 MSH 转 OBJ 导致 V 方向错误 | 导出 OBJ 时转换有纹理坐标的顶点；保留面、顶点与法线 | 较早的独立灶台 50 初态闭环中，仅此修正使成功从 3 增至 27。该数来自历史版本 |
| 单图重复的立方贴图被当作普通二维图 | 仅转换该纹理绑定的 V 方向，复用图片的其他材质保留原图 | 可见掩膜的色卡误差，Spatial 56.11 → 25.53，Goal 56.07 → 25.53，Long 74.44 → 56.04；真实贴图依次 15.91 → 15.87、15.85 → 15.61 和 37.91 → 37.81。Object 抽样画面无可测的这种贴图区域 |
| 有材质的 STL 未提供 UV | 依据原生编译后的网格坐标生成 MuJoCo 隐式平面映射，并保存对应几何的局部姿态；只替换不参与碰撞的视觉网格 | 22/40 场景含适用网格。真实材质区域中，Spatial 外部/腕部 MAE 从 141.94/133.71 降至 63.90/52.05，Goal 从 139.61/129.83 降至 64.05/53.67，Long 从 135.00/136.55 降至 79.79/81.57 |
| 原生关节状态联动的可视指示缺失 | 导出原生阈值，按同一关节规则显示或隐藏可视图元；该图元质量、碰撞掩码均为零 | 开→关往返验证覆盖 Spatial、Goal、Long。开关切换分别有 220、240、456 像素显著改变，返回起始状态的残余分别为 7、14、16 像素 |

两端渲染器的材质着色仍有可测误差。全局 gamma 1.28 在 Object 两张留出腕部图像将误差约从 31 增到 38，因此未采用。相机过渡在正式回合开始前等待资产加载，真实闭环始终使用 MotrixSim 的两路 RGB。纹理诊断覆盖可见材质抽样，不等同于 2,000 回合逐帧像素等价。

## 任务语义与可复现性

四套件的 2,000 个官方初态逐一匹配平台参考的 SHA-256。Spatial 的 500 个家具布局还与历史原生闭环逐例一致。按原 LIBERO 的对象、区域和关节谓词求值，覆盖 On、In、Open、Close、Turnon 和多条件合取。40 项任务共验证 260 个带真值的测试状态，其中 60 个阳性、200 个阴性，全部与参考一致。原生谓词不要求释放的任务维持原判分规则。

复现所用的 LIBERO 源码提交为 `8f1084e3132a39270c3a13ebe37270a43ece2a01`。平台的评测与策略代码可由 sim-platform 提交 `58f12af136f82a7316935d9afbaee6323d543100` 取得。两个 RTX 4090 上的四个策略流分别独立播种，套件内保持原顺序。最终 40 份场景保存了转换配置和 XML 指纹。每个套件的第 0 项初态 00 从原导出入口全新生成后，场景字段、XML 和初态均与计分输入一致。

动力学剩余偏差包括接触流形的点数和冲量分配、摩擦约束离散与 SDK 的浮点精度。2 ms 时闭环或固定动作仍可随时间分叉。补偿施加在 MotrixSim 的关节与刚体接口，运行评测时由其社区版后端积分与求解；MuJoCo 用于导出和独立对照。

## 内存修复后的真实 π0.5 闭环

11 月 19 日在 MotrixSim 社区版上独立运行 Spatial 任务 07（从灶台取黑碗放到盘里），使用官方初态 00–11、冻结 π0.5、真实双相机图像、完整 220 步上限。策略种子 7，环境种子 0。专用试跑从自己的策略随机流起点开始。全量套件另从任务 00、初态 00 开始，单独计分。

| 试跑指标 | 结果 |
|---|---:|
| 任务成功 | 11/12（91.7%） |
| 达到动作上限 | 1/12（初态 01） |
| 执行异常 | 0 |
| 策略进程 / 策略复位 / 前向调用 | 1 / 12 / 318 |
| 评分动作 | 1,565 |
| 仿真进程退出 | 4 批，每批 3 例 |
| 作业整体内存峰值（内核 cgroup 计数，含文件缓存） | 15.89 GiB |
| 采样到的作业交换峰值 | 0 GiB |
| 采样到的主机最低可用内存 | 44.53 GiB |

第 6、9、12 例写出后，在未观察到存活仿真子进程的采样中，作业匿名内存最低分别为 3.41、3.30、3.30 GiB。四个短生命周期仿真进程的峰值常驻内存均在 1.61–1.67 GiB 之间。工作站一次只运行一个套件，策略推理使用 GPU 1，作业内存软阈值 24 GiB、硬上限 32 GiB。数值适用于本轮 12 例；完整四套件另行统计。
